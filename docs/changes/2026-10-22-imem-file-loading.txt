   - 加载不消耗仿真时间，后续复位释放和采样时间不变。
   - 加载后打印文件路径和字数，便于确认本次实际使用的程序。

二、文件格式和路径约定

IMEM 数组元素为 32 位字；镜像第一个字进入 mem[0]，对应 CPU 字节地址 0。
下一字进入 mem[1]，对应 CPU 字节地址 4，以此类推。
未加载位置保留 RTL 初始化的 NOP。
镜像文件名的相对路径以运行 ./simv 时的工作目录为准，不以 TB 文件目录为准。
当前不支持稀疏 @地址格式、Intel HEX、ELF 或原始二进制文件直接加载。
未来 FPGA 初始化需要单独适配，不会将 TB 的 plusargs 和文件读取逻辑综合进硬件。

四、手动编译和运行（CentOS Bash）

cd ~/projects/cpu-core
mkdir -p build/cpu_smoke
cd build/cpu_smoke
vcs -full64 -sverilog -timescale=1ns/1ps ../../rtl/*.v ../../tb/tb_cpu_top.sv -top tb_cpu_top -o simv -l compile.log
vcs_rc=$?
printf 'Compile exit code: %s\n' "$vcs_rc"
tail -n 20 compile.log

编译没有错误且完成链接后再运行：
./simv +IMEM=../../sw/images/smoke.hex -l run.log
sim_rc=$?
printf 'Simulation exit code: %s\n' "$sim_rc"

+IMEM 是 TB 使用 $value$plusargs 读取的运行参数，不是 VCS 自动提供的程序加载功能。
